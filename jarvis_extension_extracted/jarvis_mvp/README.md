# JARVIS MVP extension
Drop the backend/app/jarvis and backend/app/api/jarvis.py folders into the existing project. Add the router from integration/main_router.txt. Add `openai`, `pypdf`, `scikit-learn`, `python-multipart`, and `requests` if not already installed. Put the variables in `.env`. The AI parser uses an LLM when OPENAI_API_KEY is present and a deterministic fallback otherwise. RAG is local TF-IDF over the Hadoop PDF. HDFS execution is delegated to the existing Level 6 API, not reimplemented. Voice STT/TTS is Python-side; the frontend only captures microphone audio and plays returned audio.
